# Usf — Portfolio (GitHub: Godde3s)

Personal portfolio of **Usf** — Software engineer && system designer.

Live: https://godde3s.github.io/

## About

A deliberately simple, single-page portfolio built with plain HTML, CSS and vanilla JavaScript — no frameworks, no build step. The visual language is inspired by [fenrir.lio.id](https://fenrir.lio.id): cream paper background, editorial serif display type, hairline dividers, a red accent and a "Pause motion" accessibility control. The line-art wolf is the Fenrir-inspired mascot of the site.

## Sections

- Hero — open-to-work tag, "- Interested in learning !!" kicker, "Software .eng && System designer" headline, floating wolf mascot (ground shadow + pointer parallax, honors the pause-motion control)
- In numbers — stats band (repos, projects, languages)
- Selected work — 17 compact project cards with category filter chips (Frontend & Web / Backend & APIs / AI & Automation / Apps / Infra & Industrial), including this portfolio itself, fa-guides and the Usf Resume WordPress plugin
- Project stories — MacBook slider featuring VeilChat (P2P encryption), Whisker (maintained Ruby platform), Goftego (realtime full-stack) and Anti-Treason Bot (Cloudflare Workers, 352 tests); every slide opens its repository. Touch swipe enabled

WordPress), backend & APIs (language stack cards: Python, Node.js, Go, C#), databases, system design, desktop/IoT/industrial, DevOps & cloud (AWS, Cloudflare, Vercel…), learning now (Astro on Cloudflare Workers)
- How it works — three steps, AI agent team emphasized
- Footer — CTA, link columns and a giant USF wordmark
